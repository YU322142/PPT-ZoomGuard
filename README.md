# PPT-ZoomGuard · 课程缩放防误触

[下载 v0.2.1-preview](https://github.com/YU322142/PPT-ZoomGuard/releases/tag/v0.2.1-preview) · [源代码](https://github.com/YU322142/PPT-ZoomGuard) · [MIT 许可证](LICENSE)

用于教室触摸大屏授课：正常全屏放映时阻止双指缩放误触进入幻灯片平铺总览，需要缩放时通过 PowerPoint 原有放大镜临时放开。没有常驻按钮或提示文字。

适用测试环境：Windows 11、64 位 PowerPoint 2024，版本 2408，Build 16.0.17932.21056。

## v0.2.1：增加独立的选页兜底

**用户实机反馈 v0.2.0 仍能进入选页；本机未复现该设备上的漏拦截原因。v0.2.1 增加独立兜底，真实大屏效果仍待复测。**

保留原生触摸过滤，同时监测 PowerPoint 自身的选页状态：发现选页界面打开后自动关闭，并重新锁定缩放。该保护独立于触摸驱动的输入路径，在临时放大模式中也生效。通过窗口显示事件及约 60 毫秒的定时检查触发；实际响应时间取决于 PowerPoint 是否繁忙。

**兜底是在界面出现后关闭，可能短暂闪现；通过菜单或快捷键手动打开的选页界面也会关闭。** 不应将它描述为任何设备上都绝不出现选页画面。正常视频点击、单指滑动和原有放大镜入口继续保留。

## v0.2.0 的改动

**移除 v0.1.0 覆盖整个放映画面的透明输入层，保留 PowerPoint 原生单指点击、拖动和滑动路径。** 旧版用户反馈的“视频点击没有反应”和“左侧菜单栏被挡住”是本次重构的原因。

新版直接在放映窗口收到原生触摸消息时检查触点。出现第二个手指后，取消这次多指操作；单指、鼠标和笔输入继续交给 PowerPoint，不再将单指点击重建为发往放映主窗口的鼠标消息。

当前实现仍会限制正常模式下的其他多指触摸操作，并不区分双指捏合和双指平移。单指滑动翻页保留。视频控件、菜单和批注在各型号大屏上的兼容性仍需实测。

## 安装与升级

1. 保存课件并完全关闭 PowerPoint。
2. 下载上方 Release 页面的 **PPT-ZoomGuard-0.2.1-preview-win64.zip**，完整解压。
3. 双击 **Install.cmd**，看到安装完成后，再打开 PowerPoint。

已通过正式安装包装过 v0.1.0 或 v0.2.0 时，可按上述步骤直接升级。GitHub 自动生成的源码压缩包没有编译后的 DLL，不能直接安装。

安装仅针对当前 Windows 用户，不需要更改大屏驱动或启用 PPT 宏。安装程序不更改 Office 的加载项安全策略。

## 使用

- **正常放映**：双指捏合受到限制；单指点击视频、滑动翻页等由 PowerPoint 原生处理。
- **临时缩放**：使用 PowerPoint 原有菜单或放大镜入口，选择“放大幻灯片”，再选定放大区域。设备原生支持长按右键时，也可以从长按菜单进入；新版不额外模拟长按右键。
- **退出缩放**：使用 Esc、原生右键退出或换页，随后恢复多指限制。再次点击放大镜、直接捏合缩回整页等其他退出方式尚未逐一验证。
- **卸载**：保存课件、完全关闭 PowerPoint，再双击 **Uninstall.cmd**。

## 验证范围与已知限制

在上述 Office 版本中，使用临时测试课件和 Windows 触摸注入验证了：

- 未加载组件时，双指缩小会进入平铺总览；加载新版后未进入总览，也没有意外翻页。
- 绕过触摸过滤，通过 PowerPoint 自身接口直接打开选页时，兜底自动关闭，当前页保持不变；退出放大镜后重复测试也会关闭。
- 单指滑动从第 2 页返回第 1 页。
- 手指点击内嵌测试视频后，实际播放进度持续前进。
- 视频区域和空白区域的双指展开、两指先后落下及先后抬起均受到限制。
- 连续取消多指操作后，视频仍能点击播放。
- 原生菜单进入放大镜后允许双指缩放，原生右键退出后重新锁定。选定放大区域的这一步使用鼠标完成，纯触屏入口仍需大屏实测。

这些是自动化环境中的验证，不能替代教室大屏验收。v0.2.0 已有实机失效反馈，v0.2.1 仍需在该设备复测。

请在实际大屏上检查视频播放、暂停和进度条拖动、左侧菜单栏、左右滑动翻页、批注，以及退出缩放后是否重新受到保护。多屏、演示者视图、窗口式放映、压感笔、第三方批注软件、其他 Office 版本和视频格式尚未完成兼容性验证。新版保留原生笔输入路径，但不据此宣称所有批注功能已通过。

## 排查

安装后没有效果时，到“文件 → 选项 → 加载项”，底部选择“COM 加载项 → 转到”，检查“课程缩放防误触（实验版）”是否勾选。也可以在这里临时停用组件，比较同一课件的原生行为。

如果仍有失效，请在复现后保持 PowerPoint 打开，双击安装包中的 **Diagnostics.cmd**。它仅查询安装版本、实际加载版本、保护状态和最近日志，将结果保存为同文件夹的 **ZoomGuard-Diagnostics.txt**；不会安装、启用或卸载组件。有多个 PowerPoint 实例时，它读取系统返回的活动 COM 实例，可能不是正在放映的那个实例。

日志位于 `%LOCALAPPDATA%\LessonZoomGuard\guard.log`，默认记录连接与模式切换，不记录幻灯片文字或截图，不连接网络。
