# PPT-ZoomGuard · 课程缩放防误触

[下载 v0.1.0-preview](https://github.com/YU322142/PPT-ZoomGuard/releases/tag/v0.1.0-preview) · [源代码](https://github.com/YU322142/PPT-ZoomGuard) · [MIT 许可证](LICENSE)

适用测试环境：Windows 11、PowerPoint 2024，版本 2408，Build 16.0.17932.21056，64 位。

这是供教室实测的原型。正常放映时没有常驻按钮或提示文字，默认过滤双指操作；使用 PowerPoint 原有放大镜时临时恢复缩放。

## 人工智能生成内容说明

本项目的代码、安装与卸载脚本及文档主要由人工智能工具 **OpenAI Codex** 根据维护者提出的需求生成，并通过多轮对话调试与修改。

维护者提供功能需求、教室大屏实机测试和使用反馈。已完成的验证范围与已知限制见下文及[开发说明](source/DEVELOPMENT.md)。

## 已知限制：左侧菜单栏也会被屏蔽

**用户在教室大屏实测确认：缩放屏蔽有效，但左侧菜单栏也会被一并屏蔽。本版本保留该行为，不修复。**

需要使用左侧菜单栏时，可先结束放映，再到 PowerPoint 的 COM 加载项中停用本组件，或使用卸载工具。需要临时缩放时，优先使用下文的长按原生菜单入口。

## 安装

1. 保存课件并完全关闭 PowerPoint。
2. 从上方 Release 页面下载安装包，完整解压到一个文件夹。GitHub 的源码压缩包不包含编译后的 DLL，不能直接安装。
3. 双击 **Install.cmd**，看到“安装完成”后，再打开 PowerPoint。

安装仅针对当前 Windows 用户，不需要修改大屏驱动，也不需要开启 PPT 宏。安装程序将组件保存到当前用户的本地应用数据目录。

## 使用

- **正常放映**：双指缩小不会进入平铺总览；单指点击翻到下一页，左右滑动可以翻页。
- **需要缩放**：在画面上长按约一秒，松手后，在 PowerPoint 原有菜单中选择“放大幻灯片”，再点选要放大的区域。原有放大镜入口可用时，也可以直接使用它；左侧菜单栏受限的情况见上文。
- **结束缩放**：按 **Esc**，或使用 PowerPoint 原有的右键退出动作，恢复整页后会自动重新过滤双指操作。触屏的原生长按右键是否可用，取决于设备设置。
- **切回编辑窗口或其他应用**：过滤层会自动隐藏；返回放映时恢复。

首版已验证的自动重新锁定入口是 **Esc、右键退出缩放，以及换页**。再次点击放大镜、直接捏合缩回整页等其他退出方式，尚未逐一验证；测试时请优先使用 Esc 或右键。

## 第一次在教室测试

请先用一份测试课件依次检查：

1. F5 开始普通全屏放映，尝试双指缩小，确认没有平铺总览、没有意外翻页。
2. 用单指点击和滑动，确认能正常翻页。
3. 打开放大镜，确认双指放大、缩小恢复正常。
4. 使用 Esc 或右键退出缩放，再尝试双指缩小，确认重新受到保护。
5. 检查实际使用的批注软件、画笔、橡皮擦，以及切换窗口和结束放映。

**批注兼容还需要真实大屏验证，尚未列为通过项目。** 在当前自动化环境中，停用加载项后的原生触摸批注基线也没有产生笔迹，不能据此确认实际大屏上的批注效果。请通过上述检查后再用于授课。

首版针对普通全屏放映；演示者视图、多屏、窗口式放映、压感笔和第三方批注工具尚未完成实测。单指批注输入包含转发逻辑，可能需要针对实际设备继续适配。

## 实测反馈

- 用户实机反馈：双指缩放屏蔽成功。
- 用户实机反馈：左侧菜单栏同时被屏蔽，接受保留这一限制。
- 上述反馈不代表批注、多屏、其他 Office 版本等全部兼容性项目已经通过。

## 卸载与排查

保存课件、完全关闭 PowerPoint，然后双击 **Uninstall.cmd**。

安装后没有效果时，可到“文件 → 选项 → 加载项”，底部选择“COM 加载项 → 转到”，检查“课程缩放防误触（实验版）”是否已勾选。安装包不更改 Office 的加载项安全策略。

组件日志位于 `%LOCALAPPDATA%\LessonZoomGuard\guard.log`。默认日志记录连接和模式切换，不记录幻灯片文字或截图，不连接网络。

`source` 文件夹包含源代码和重新编译说明。
